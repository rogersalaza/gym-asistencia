# Control de asistencia para gym

Mini app de recepción para un gimnasio: registra entradas y salidas, muestra cuánta gente hay dentro contra el aforo (Libre / Concurrido / Lleno), la hora pico, la estancia promedio y la afluencia por hora.

- Un solo archivo: `index.html`. Se abre en cualquier navegador, sin instalar nada.
- Los registros se guardan solo en el navegador de quien la usa.
- Incluye datos de ejemplo.
